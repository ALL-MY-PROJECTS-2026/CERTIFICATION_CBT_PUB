소개

CBT 전자문제집은 자격증을 준비하는 분이 개념을 읽고, 그 자리에서 바로 문제를 풀어 이해를 확인할 수 있도록 만든 온라인 학습 사이트입니다.

이론만 길게 읽으면 금방 지치고, 문제만 풀면 왜 틀렸는지 남지 않습니다. 그래서 이 사이트는 한 단원 = 핵심 개념 + 확인 문제를 한 화면에 담습니다. 읽고 → 풀고 → 해설로 정리하는 흐름을 짧게 반복하며 실력을 쌓아 나갑니다.

다루는 내용

  • 과목별 개념 정리 — 시험 범위를 단원 단위로 쪼개, 꼭 필요한 개념만 교재처럼 정리합니다.
  • 개념 확인 문제 — 각 단원 끝에 OX·4지선다 문제를 두어 방금 읽은 내용을 바로 점검합니다.
  • 틀린 문제 다시 보기 — 채점 결과는 브라우저에 저장되어, 약한 부분을 다시 확인할 수 있습니다.

현재 정보처리기사를 시작으로 과목과 단원을 하나씩 넓혀 가고 있습니다.

학습 방법

  1. 왼쪽 과목 목록에서 공부할 과목을 고릅니다.
  2. 단원 글을 읽으며 개념을 잡습니다.
  3. 글 하단의 문제를 풀고 해설로 정리합니다.

콘텐츠 원칙

  • 검증되지 않은 내용은 싣지 않으며, 시험 기준이 바뀌는 부분은 기준 시점을 함께 밝힙니다.
  • 문제와 해설은 학습 목적에 맞게 직접 작성합니다.
  • 잘못된 부분은 제보해 주시면 확인 후 정정합니다. → 문의

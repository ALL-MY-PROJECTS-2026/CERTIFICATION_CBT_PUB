식별자(Identifier) — SQLD 최다 함정, 특징·분류·식별관계 정리

CBT 전자문제집 편집팀2026년 7월 27일 13:00
#SQLD#식별자#주식별자#본질식별자#인조식별자

식별자(Identifier) 는 엔터티의 각 인스턴스를 구분하는 속성(또는 속성 묶음) 입니다. 사원의 사원번호, 주문의 주문번호가 식별자입니다. 이 단원은 SQLD 1과목에서 가장 헷갈리게 내는 부분 이라 특징·분류·관계를 정확히 나눠 익혀야 합니다.

이 단원, 시험에서 어디에 나오나

  • 제1과목 「데이터 모델링의 이해」(10문항·20점)의 핵심이자 최다 함정 영역 입니다.
  • 주식별자 4대 특징, 본질 vs 인조, 식별 vs 비식별 관계 세 가지가 단골입니다.

① 주식별자의 4대 특징

그림 1. 유일성·최소성·불변성·존재성. 최소성(속성 개수)과 존재성(NULL 불가)의 정의를 바꿔 내는 함정이 잦습니다. (자작 도식)

특징뜻
유일성모든 인스턴스를 유일하게 구분
최소성유일성을 만족하는 최소 속성 수
불변성값이 잘 바뀌지 않음
존재성반드시 값 존재(NULL 불가)

함정: 최소성(속성을 꼭 필요한 만큼만)과 존재성(NULL 금지)의 정의를 서로 바꿔 낸 보기.

② 식별자 분류 — 본질 vs 인조가 핵심

식별자는 여러 기준으로 나뉩니다. 시험은 특히 본질 vs 인조 를 묻습니다.

기준종류
대표성주식별자 / 보조식별자
생성 위치내부식별자 / 외부식별자
속성 수단일식별자 / 복합식별자
대체 여부본질식별자 / 인조식별자
  • 본질식별자: 업무에 원래 존재하는 키(주민번호, 사업자번호).
  • 인조식별자: 업무에 없던 것을 인위적으로 만든 대체키(일련번호, 자동 채번 ID).

인조식별자는 본질식별자가 너무 길거나 복잡할 때 대신 쓰는 대체키 입니다.

③ 식별관계 vs 비식별관계

부모의 키가 자식으로 내려올 때, 자식의 주식별자에 포함되면 식별관계, 일반 속성(FK)이 되면 비식별관계 입니다.

그림 2. 부모 키가 자식 주식별자에 들어가면 식별(실선), 일반 속성이면 비식별(점선)입니다. (자작 도식)

구분부모 키 위치표기종속
식별관계자식 주식별자에 포함실선강함
비식별관계자식 일반 속성(FK)점선약함

자주 틀리는 함정

  • 본질 vs 인조 뒤집기 — 일련번호(인조)를 본질로, 주민번호(본질)를 인조로.
  • 최소성 ↔ 존재성 — 정의를 서로 바꿔 낸 보기.
  • 식별 ↔ 비식별 — 실선/점선, 주식별자 포함 여부를 반대로 설명.

한 장 정리 (암기 카드)

  • 주식별자 4특징: 유일·최소·불변·존재(NULL 불가).
  • 분류: 대표성·생성·속성수 + 본질(원래 있음) / 인조(새로 만든 대체키).
  • 식별관계: 부모 키가 자식 주식별자에 포함(실선, 강함).
  • 비식별관계: 부모 키가 자식 일반속성(점선, 약함).

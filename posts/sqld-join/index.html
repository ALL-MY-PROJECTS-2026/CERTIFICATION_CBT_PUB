SQL JOIN 완전정복 — SQLD 시험에 나오는 조인 총정리

JungWooGyun2026년 7월 25일 09:00
#SQLD#SQL#조인#JOIN#OUTER JOIN#데이터베이스

JOIN(조인)은 여러 테이블을 공통 컬럼(키)으로 이어 하나의 결과 집합으로 만드는 연산입니다. 관계형 DB는 데이터를 나눠 저장하므로(정규화), 조회 시 조인으로 다시 합칩니다.

그림 1. 공통 키(회원번호)로 두 표를 이으면 짝이 맞는 행만 결과에 남습니다. 주문이 없는 '박'은 INNER에서 빠집니다. (자작 도식)

출제 포인트 — SQLD가 조인에서 묻는 것

  • 조인 종류 구분: INNER / LEFT · RIGHT · FULL OUTER / CROSS / SELF 가 각각 어떤 행을 남기는지.
  • NULL 처리: OUTER JOIN에서 짝 없는 쪽이 NULL로 채워지는 동작.
  • ANSI 문법 vs 오라클 전통 문법((+))의 대응 관계.
  • **ON · USING · NATURAL**의 차이와 제약.
  • 함정: 아우터 조인에서 조건을 ON에 두느냐 WHERE에 두느냐에 따라 결과가 달라지는 것.

문법 — ANSI 표준과 오라클 전통 표기

-- ANSI 표준(권장): JOIN ~ ON
SELECT m.이름, o.금액
FROM   회원 m INNER JOIN 주문 o
       ON m.회원번호 = o.회원번호;

-- 오라클 전통: FROM 에 나열 + WHERE 로 연결
SELECT m.이름, o.금액
FROM   회원 m, 주문 o
WHERE  m.회원번호 = o.회원번호;      -- INNER JOIN 과 동일

아우터 조인의 오라클 (+) 표기 — (+)는 부족한(NULL 채울) 쪽에 붙입니다.

-- 회원 전부 + 주문 없으면 NULL  (= LEFT OUTER JOIN)
SELECT m.이름, o.금액
FROM   회원 m, 주문 o
WHERE  m.회원번호 = o.회원번호(+);   -- (+) 가 주문 쪽 → 주문이 옵션

m.회원번호 = o.회원번호(+) 는 회원 m LEFT OUTER JOIN 주문 o 와 같습니다. (+)가 붙은 쪽(주문)이 없어도 반대쪽(회원)은 남습니다.

종류별 결과

조인남는 행짝 없을 때
INNER JOIN양쪽 조건이 일치하는 행만제외
LEFT OUTER왼쪽 전부 + 오른쪽 일치분오른쪽 컬럼 NULL
RIGHT OUTER오른쪽 전부 + 왼쪽 일치분왼쪽 컬럼 NULL
FULL OUTER양쪽 전부없는 쪽 NULL
CROSS JOIN두 표의 모든 조합(m×n)(조건 없음)
SELF JOIN같은 표를 별칭 2개로 조인조건에 따름

그림 2. 노란 영역이 각 조인이 반환하는 행입니다. INNER=교집합, LEFT/RIGHT=한쪽 전체, FULL=합집합. (자작 도식)

-- SELF JOIN: 사원과 그 관리자(같은 EMP 테이블)
SELECT e.이름 AS 사원, mgr.이름 AS 관리자
FROM   사원 e LEFT JOIN 사원 mgr
       ON e.관리자번호 = mgr.사원번호;

ON · USING · NATURAL 차이

FROM a JOIN b ON a.부서코드 = b.부서코드   -- ON: 조건을 직접 명시(가장 유연)
FROM a JOIN b USING (부서코드)             -- USING: 같은 이름 컬럼 1개로, 결과에 부서코드 1번만
FROM a NATURAL JOIN b                      -- NATURAL: 같은 이름 컬럼 전부 자동 조인
  • USING·NATURAL의 공통 컬럼에는 테이블 별칭을 붙이면 안 됩니다(예: SELECT 부서코드 O, a.부서코드 X).
  • NATURAL JOIN은 의도치 않은 컬럼까지 조인 기준이 될 수 있어 시험에서 주의 대상입니다.

핵심 규칙 · 자주 틀리는 함정

함정 1 — 아우터 조인의 ON vs WHERE. 왼쪽을 다 남기려고 LEFT JOIN을 써도, 오른쪽 테이블 조건을 WHERE에 두면 그 NULL 행이 걸러져 INNER처럼 됩니다.

-- (의도) 모든 회원 + 2026년 주문. (실수) 주문 없는 회원이 사라짐
FROM 회원 m LEFT JOIN 주문 o ON m.회원번호 = o.회원번호
WHERE o.주문일 >= '2026-01-01';     -- o.주문일 이 NULL 인 행이 탈락 → INNER 효과
-- (정답) 조건을 ON 으로:
FROM 회원 m LEFT JOIN 주문 o
     ON m.회원번호 = o.회원번호 AND o.주문일 >= '2026-01-01';

함정 2 — ON 조건 누락 = 카티션 곱. 연결 조건을 빠뜨리면 CROSS JOIN이 되어 행 수가 두 표 행수의 곱으로 폭발합니다.

한 장 정리 (암기 카드)

  • INNER = 교집합, LEFT/RIGHT = 한쪽 통째 + 반대쪽 NULL, FULL = 합집합, CROSS = 곱.
  • 오라클 (+)는 NULL 채울(옵션) 쪽에 → a = b(+)는 a를 다 남기는 LEFT.
  • OUTER에서 반대쪽 필터는 ON에(WHERE에 두면 INNER처럼 됨).
  • USING·NATURAL 공통 컬럼엔 별칭 금지.
